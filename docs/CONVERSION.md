# 页面优化与收益入口验收

## 2026-10-23

本轮只优化静态页面与抓取输出。不增加转化统计、账户或后台，不声称已验证佣金入账。

### 页面路径

- 首屏提供低预算年付、最近发布、标注在售三个快捷筛选；商家目录默认折叠。
- 首屏常驻 RackNerd、DMIT、DeluxHost 三个推广入口，完整目录保留全部 14 家个人 AFF，发布门禁逐家核对。
- 每条优惠提供商家主入口和可键盘操作的详情按钮。详情保留原帖，取消旧 LowSeek 论坛跳转。
- 默认隐藏售罄、结束、补货中和疑似售罄；显式选择状态时允许查看这些记录。
- 年付预算仅比较明确年付的报价，按固定近似汇率换算欧元，不将月付折算误称为年付套餐。
- 移动端使用单列卡片，桌面保留表格。没有 JavaScript 时仍有服务端生成的价格、商家链接。
- 优惠码支持复制及失败提示。未确认库存使用“到商家核对价格与库存”，售罄使用“查看补货与替代套餐”。

### 数据边界

全文规格的最大值不能与独立价格拼成一个套餐。仅有表格套餐及明确价格周期时展示绑定套餐；否则展示帖文涉及的配置范围与“帖文报价，未与配置绑定”。表格裸价格不得默认当成年付。无法从价格表头确定周期时显示待核对。

信息完整度仅为字段覆盖率，不代表准确率、商家质量或库存保证。保留公开原帖和库存证据。来源帖文里的价格、赠品和折扣仍可能过期，页面明确要求核对首期、续费、税费和限制。

品牌前缀修复 LayerOne / SVR4U；当原商家名识别失败时，仅在正文存在唯一合格购买域名时恢复入口，多个域名时不猜测。没有注册推广的商家不伪造推广 ID。

### 推广配置

商家目录与优惠链接共用 `letdeals/affiliate.py`，避免两份 ID 漂移。保留现有 14 家标识，整链接模式不会擅自发明深链参数。`LDR_AFFILIATES` 仓库变量可覆盖映射。

是否计佣仍取决于商家规则、Cookie、账户状态和订单资格。不能用“链接参数正确”代替后台归因验证。部分未配置商家的原帖链接可能带来源方参数，不能宣称所有出站链接均产生本站佣金。

### 发布与回归

```sh
python -m pytest tests -q
python -m letdeals --with-replies --recent-days 90
python -m tools.audit_site
```

发布检查涵盖推广 ID 幂等性、安全 URL、价格说明、已结束活动按钮和旧论坛链接。Actions 每次刷新后执行检查，再提交产物。部署后需要比对线上 HTML 与仓库产物，并验证手机布局、筛选、详情、复制和商家链接。

任一请求的数据源抓取失败或为空时，CLI 拒绝覆盖旧站点，避免只剩单一来源导致大批优惠和 AFF 消失。

本轮新增单元测试覆盖真实问题模式，不保证所有第三方帖文均能正确解析。价格表结构不明确时选择保守展示，不以提高点击率为由制造优惠或库存承诺。
